# Muzun AlHallabi — Public Portfolio

This is a static, view-only copy of the portfolio. It has no in-browser editor, upload controls, or browser storage. Existing portfolio images and the internship certificate are included so they display on GitHub Pages.

## View locally

Open `index.html` in a browser.

## Publish with GitHub Pages

Upload the contents of this folder to a GitHub repository, then enable GitHub Pages for the repository's `main` branch and root folder in **Settings → Pages**. The portfolio is a plain static site and needs no build step.

To update the public content before publishing, edit `content.js` and the site files directly.
